## 4. 세력 내부 파벌·제도 모델링

| 출처 | 어떻게 | 우리 적용 |
|---|---|---|
| EU4 Estates https://eu4.paradoxwikis.com/Estate_modding | 신분집단은 국가 내부 객체: trigger·base_influence·country_modifier·privileges·agendas. loyalty × influence 2축 | `faction`(원로원파·민중파·기사계급·군단병)에 influence·loyalty를 시대별 history로. 특권=`institution`과 `grants` |
| CK3 Council / Factions https://ck3.paradoxwikis.com/Council_modding · https://ck3.paradoxwikis.com/Factions | 직위(council position)가 객체, 인물은 holder. 파벌 = 유형 + leader + members + discontent + demand → 최후통첩 → 내전 | `office{name, max_holders(콘술 2), term, eligibility}` + `history[{date, holder}]`. `faction{type, leader, members, demand}` → conflict 사건 |
| Total War: Rome 2 정치 https://r2edenc.totalwar.com/manual/rome-ii-politics-overview/index.html | 세력 안 2~5개 정파(Julia·Cornelia·Junia + Claudia·Fabia·Papiria·Servilia). gravitas → influence(%), loyalty 낮으면 분리. 정부형태 전환 | `faction.subtype = gens/house`로 씨족을 정파와 분리. 인물→가문 `member_of`, 가문→정파 `aligned_with`. `government_form`을 시대별 history로 |
| Civ5/Unciv Policies·Beliefs | 정책 트리 = branch → policies(requires[]) | `institution.requires[]`·`established_by` → 12표법→호르텐시우스법 제도 트리 |

## 바로 넣을 패턴 5개

1. base + history[] 분리 — 모든 노드는 불변 속성 + `history:[{date, patch}]`, 연도 지도는 접기(fold)로 재구성.
2. 자리(office)를 1급 객체로, 인물은 holder — `office.history`에서 `holds_office` 파생. 콘술 2인·임기 1년 제약은 office에.
3. 소유/지배/권리 3분 — `controls` / `claims` / `core`.
4. 파벌 2축 상태 — `faction`에 시대별 influence·loyalty·type·leader·members·demand, 사건과 `triggers`.
5. 문자열 Type 키 + 정션 테이블 / LPF `when` — 참조는 `PERSON_*`, `PLACE_*`, 장소는 LPF로 내보내 WHG·Pleiades와 상호운용.
