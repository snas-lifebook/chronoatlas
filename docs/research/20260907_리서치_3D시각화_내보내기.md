## 요약

MVP: MapLibre 유지(글로브·terrain·hillshade·color-relief) + `fill-pattern` 해칭/`heatmap` 영향권 + flubber morph + `<model-viewer>` 인물 상세 + 0 A.D. 건물 GLB 몇 개(Sketchfab CC도 지금 확보) + `preserveDrawingBuffer` PNG + mediabunny MP4 + satori(또는 modern-screenshot) 카드 50장. 전부 정적·무료.

LVP: TRELLIS.2로 초상 50장→흉상 GLB, GLTFLoader로 지도 위 배치; deck.gl 9.4 인터리브 TripsLayer·PolygonLayer 전환; Remotion 오프라인 렌더; Cesium은 BCE 한계로 쇼케이스 옵션. Hunyuan3D는 어느 단계에도 넣지 않는다.
