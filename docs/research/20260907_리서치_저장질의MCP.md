## 권고 조합

1안 (지금 당장, 서버 0): JSONL 유지 → 빌드(TS)에서 Zod 검증 + 5종 린트 + `graph.json`·JSON-LD 생성 → Sigma.js+Graphology+`@sigma/layer-maplibre` → 자체 stdio MCP 서버(툴 4개) 동봉, PoC는 `server-memory` 변환. 외부 ID는 Pleiades·Wikidata·PeriodO 컬럼만, 장소 내보내기는 LPF.

2안 (질의 언어가 필요해질 때): LadybugDB(WASM+로컬 파일)로 Cypher 통일, MCP는 `mcp-server-ladybug`, 원본은 여전히 JSONL. 원격 MCP는 Cloudflare Workers Streamable HTTP.
