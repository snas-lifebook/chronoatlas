## 함정

- 교보재 cast 구간은 **양끝 포함**이다(`src/people.ts` `year > to_year`면 제외). 반열림으로 쓰면 죽은 사람이 한 해 더 선다(막센티우스가 313에 섰다).
- `p12-*.json`은 포인트 01·02 묶음이다. 12~14는 `p1214-*`.
- 니케아 장면에서 serve.sh 검증 Chrome이 두 번 꺼졌다. 따로 띄운 headless에서는 오류 없음.
- 초상은 `npm run adapt`가 관계분석 `_registry.csv`에서 경로를 받고, 파일은 `public/assets/portraits/*.webp`(256px)로 따로 넣어야 한다. 경로만 있고 파일이 없으면 조용히 빈다.
