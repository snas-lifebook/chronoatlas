# River의 요청 원문

**이 파일은 요약하지 않는다.** River가 실제로 쓴 말을 그대로 옮기고, 그 아래에 그것이 무엇이 됐는지만 한 줄씩 붙인다.

왜 원문을 남기나. 이 슬라이스에서 **요약이 원인을 지워 버린 일이 여러 번** 있었다. "빗금은 무슨 표시인가?"는 범례 요구가 아니라 **범례가 없다는 증거**였고, "지도가 없으면 지형지물이나 망루나 이런 배치들이 있거나"는 기능 요청이 아니라 **대안을 허락한 말**이었다. 다듬으면 그 결이 사라진다.

> 인용 안의 `[이미지]`는 River가 첨부한 스크린샷·레퍼런스다. 실물은 대화 기록에 있고 여기엔 무엇이었는지만 적는다.
