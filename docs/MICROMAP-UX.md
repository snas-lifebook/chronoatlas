# 미시 지도 UX·UI 설계

> River의 요구를 그대로 옮긴다.
>
> *"알레시아 공성전, 로마 도시, 알렉산드리아 도서관 도시 등등 필요한 미시맵을 더 정의하라. 각 미시맵은 좀 더 (레퍼런스 이미지들) 이런 느낌들을 자아내면 좋겠다. 그리고 미시맵에서 망루의 특징이라던지, 지형의 특징이라던지, 군단이나 군대의 특징, 뭐 그런 것들을 어노테이션 인포그래픽, 콜아웃 인포그래픽, 분해도 다이어그램으로 표시할 수 있도록(각 정보들은 위키백과나 웹 이미지들을 잘 연결해놓아서 그걸 볼 수 있도록 한다. UXUI를 설계해서 문서로 보관하라.)"*

이 문서가 그 보관본이다. 구현된 것과 아직 아닌 것을 갈라 적는다.

---

## 1. 레퍼런스에서 뽑은 문법

River가 붙인 일곱 장이 전부 같은 한 가지를 하고 있었다.

| 레퍼런스 | 뽑아 쓴 것 |
|---|---|
| 수사(Susa) 유적 번호 지도 | 지도 위에는 **번호만**. 이름은 여백의 범례로 뺀다 |
| 아크레 1291년 성벽·탑 | 지시선으로 성벽의 각 탑에 이름을 건다. 지도 안에 글을 안 욱여넣는다 |
| 스페인 내전 참호 분해도(E. Amade) | 구조물을 **잘라 보여 주고** 각 부위에 설명을 단다. 「거리는 표현을 위해 조정했다」고 적어 둔다 |
| 로크루아 전투 배치도 | 부대를 블록으로, 기동을 화살표로. 아래 캡션에 전황 요약 |
| USGS 지형도 + 표기 | 실측 바탕 위에 손그림 표기를 얹는다. 바탕과 주석의 층이 갈린다 |
| 중국 고지도(채색 필사) | 건물 하나하나에 이름표. 축척보다 **관계**가 우선 |
| 미니어처 입체 지형 | 지형이 주인공일 때는 입체가 낫다 |

공통 규칙 셋을 채택했다.

1. **설명은 지도 밖에 둔다.** 지도 위에는 번호 핀만. 그래야 지형이 안 가려진다 — River가 바로 앞 요구에서 「지명이나 지리나 도시 위치를 가리면 안 된다」고 한 것과 같은 원칙이다.
2. **지시선이 둘을 잇는다.** 번호만으로는 어느 것이 어느 것인지 눈이 왕복해야 한다.
3. **출처를 글상자 안에 적는다.** 레퍼런스들이 전부 그렇게 한다. 사료·논쟁·불확실을 숨기지 않는다.

## 2. 화면 구조 (구현됨)

```
┌──────────────────────────────────────────────────────────────┐
│ ┌──────────────┐                                             │
│ │ 발표 HUD     │            ②                    ┌─────────┐ │
│ │ 장면 제목    │        ╱                        │ ① 카드  │ │
│ │ 설명         │   ┌───╱──────────────┐          │ 제목    │ │
│ └──────────────┘   │  ①               │ ╲        │ 본문    │ │
│ ┌─────────┐        │    지  도        │   ╲      │ 사료    │ │
│ │ ④ 카드  │────────│         ③        │─────╲────│ [링크]  │ │
│ │         │        │                  │      ╲   └─────────┘ │
│ └─────────┘        └──────────────────┘       ╲  ┌─────────┐ │
│ ┌─────────┐                                     ╲│ ③ 카드  │ │
│ │ ⑧ 카드  │                                      └─────────┘ │
│ └─────────┘                                                  │
└──────────────────────────────────────────────────────────────┘
   왼쪽 칸(300px)          지시선 SVG            오른쪽 칸(300px)
```

- **번호 핀** — 지름 22px 금색 원, 흰 테. 데이터의 `num` 순서.
- **지시선** — 카드 안쪽 모서리에서 가로로 나가다 한 번 꺾여 핀으로. 곧은 대각선은 지도 위를 길게 가로질러 지형을 덮는다.
- **카드** — 폭 300px. 제목 · 본문(160자 이내) · 사료 · 링크 줄.
- **칸 배치** — 데이터의 `side`가 좌우를 정한다. 각 칸 안에서는 `num` 순으로 균등 배분.
- **왼쪽 칸은 HUD 아래에서 시작한다.** 발표 HUD가 왼쪽 위를 쓴다. 실측한 HUD 높이를 매 프레임 읽어 그만큼 내린다.

### 키

| 키 | 하는 일 |
|---|---|
| `C` | 콜아웃 켜기·끄기. 그림만 보여 주고 싶을 때 |
| 줌 | 문턱을 넘으면 그 미시 지도가 자동으로 켜진다 |

## 3. 켜지는 규칙 (구현됨)

장면 수는 아홉으로 묶여 있다(River). 그래서 미시 지도는 **장면이 아니라 줌**으로 켠다 — 「로마로 들어가면 보여지겠지」가 맞는 동작이다.

| 미시 지도 | 문턱 줌 | 중심 | 반경 |
|---|---|---|---|
| 알레시아 | 11 | 4.4958, 47.535 | 0.6° |
| 로마 시내 | 12 | 12.4823, 41.8925 | 0.35° |
| 알렉산드리아 | 12 | 29.897, 31.199 | 0.35° |

**줌만 보면 안 된다.** 로마에서 z13으로 당겼을 때 알레시아 콜아웃이 같이 뜬다. 그래서 `microMapAt(zoom, center)`가 줌과 **거리**를 같이 본다(`src/callouts.ts`).

벡터 레이어 쪽은 줌만 본다(`syncDetailMaps`). 화면 밖 지도는 어차피 그릴 것이 없어서 성능 말고는 차이가 없다.

### 미시 축척에서 끄는 것

- **이동 경로** — 지중해를 건너는 자취라 도시 지도에서는 화면을 가로지르는 붉은 선 몇 개일 뿐이다. 알렉산드리아 시내 판에서 실제로 그랬다.

## 4. 데이터 형식

### 지형·건물 — `data/overlays/pack-<지도>.json`

`pack-alesia.json`(43) · `pack-roma-urbs.json`(31) · `pack-alexandria.json`(16). 셋 다 같은 스키마다.

```jsonc
{
  "teaching": true,
  "source": "어디서 왔는지 · 무엇이 확정이고 무엇이 복원인지 한 문단",
  "view": { "center": [lon, lat], "zoom": 13.6, "minZoom": 12 },
  "features": [{
    "properties": {
      "id": "alexandria:heptastadion",
      "name_ko": "헵타스타디온", "name_la": "Heptastadium",
      "kind": "causeway",
      "note_ko": "…",
      "source": "확정 | 근사 | 복원 | 논쟁",
      "wiki": "https://…"
    }
  }]
}
```

`source`의 네 단계가 이 데이터의 정직성 장치다 — **확정**(발굴·현존 유구), **근사**(위치는 확실, 면을 단순화), **복원**(학설로 그린 선), **논쟁**(학계가 갈림).

`kind` 어휘: `building` `hill` `wall` `river` `road` `gate` `field` `temple` `theatre` `boundary` `forum` `circus` + 알렉산드리아가 더한 `lighthouse` `island` `causeway` `harbor` `district` `cape` `lake`. **새 kind를 더하면 `engine.ts`에 그리는 레이어도 같이 더해야 한다** — 안 그러면 데이터는 있는데 화면에 없다.

### 콜아웃 — `data/overlays/pack-callouts.json`

```jsonc
{
  "id": "alesia:call-turris",
  "map": "alesia",                     // alesia | roma | alexandria
  "anchor": { "feature": "alesia:inner" },   // 또는 { "lnglat": [lon, lat] }
  "side": "right", "num": 1,
  "title": "망루 — 80로마피트마다 하나",
  "body": "2~4문장, 160자 이내",
  "cite": "카이사르, 『갈리아 전기』 7.72",
  "links": [{ "label": "…", "url": "https://ko.wikipedia.org/…" }],
  "image": { "url": "…commons…", "credit": "작자/라이선스", "alt": "…" }
}
```

**앵커는 피처 id로 건다.** 좌표를 두 군데 적으면 한쪽만 고쳐지고 어긋난다. `representativePoint()`가 점·선·면에서 대푯점을 뽑는다 — 면은 정점 평균, 선은 가운데 정점. 좌표를 못 찾은 콜아웃은 **버리고 개발 콘솔에 남긴다**. 지도 밖 (0,0)에 핀을 찍느니 없는 게 낫고, 조용히 삼키면 다음 사람이 못 찾는다.

현재 23개 — 알레시아 9 · 로마 7 · 알렉산드리아 7.

## 5. 정직성 규칙

레퍼런스 지도들이 지키는 것이고, 이 발표가 사료를 다루기 때문에 더 중요하다.

1. **숫자에는 사료를 단다.** 모든 수치에 `cite`. 사료에 없으면 「사료에 없다」고 적는다 — 망루 간격은 `BG` 7.72에 있고 망루 **높이는 없다**. 12피트는 망루가 아니라 보루의 높이다.
2. **로마자 단위는 환산 전후를 같이 적는다.** 「80로마피트(약 24m)」.
3. **학계가 갈리면 갈린다고 적는다.** 지금 세 항목이 그렇다 — 알레시아 구원군 규모(카이사르 33만 대 현대 8만~13만), 알리즈생트렌 비정의 몽 레아 문제, 알렉산드리아 도서관 화재(4만 대 40만, 그리고 본체가 탔는지 자체).
4. **링크는 실존을 확인하고 넣는다.** 19개를 Wikipedia REST API로 확인했다. 죽은 링크 0.
5. **이미지는 커먼즈 실제 파일 URL과 라이선스만.** 확인 못 하면 `null`로 둔다. 지금 11개 있고 12개가 빈칸이다 — 개념적 항목(군단 편제·구원군 규모)은 맞는 사진이 없다.

## 6. 아직 안 한 것 — 분해도(exploded diagram)

River가 말한 셋 중 **어노테이션**과 **콜아웃**은 위로 구현됐다. **분해도는 아직이다.**

분해도가 필요한 대상은 명확하다 — 알레시아의 **세 겹 함정**(킵피·릴리아·스티물루스)과 **이중 포위선 단면**이다. 참호 분해도 레퍼런스가 하는 일이 정확히 그것이고, 이건 **지도가 아니라 단면도**라 MapLibre 위에 그릴 물건이 아니다.

설계는 이렇게 둔다.

- **SVG 한 장.** 지도 좌표가 아니라 개념 좌표다. 카드를 클릭하면 그 자리에 펼쳐지는 패널로.
- 왼쪽에서 오른쪽으로: 들판 → 릴리아(구덩이) → 스티물루스(말뚝) → 킵피(가지 박은 도랑) → 해자 둘 → 보루와 망루. 각 층에 치수와 사료.
- **레퍼런스가 적어 둔 정직성 문구를 그대로 쓴다** — 「거리는 표현을 위해 조정했다」. 단면도는 축척이 아니다.
- 데이터는 `pack-callouts.json`에 이미 있다(`alesia:call-traps`). 그림만 없다.

같은 방식으로 로마 시내는 **포메리움 단면**(도시 안 / 포메리움 / 마르스 광장 / 군대)이 후보다. 루비콘이 왜 사건인지가 그 한 장으로 설명된다.

## 7. 손볼 자리

- **카드 높이를 안 재고 균등 배분한다.** 본문이 160자로 묶여 있어 지금은 안 넘치지만, 긴 카드가 들어오면 겹친다. 재려면 한 번 그리고 나서 다시 배치해야 하는데(2패스) 그만한 값어치가 아직 없다.
- **정지 이미지로 구울 때 안 담긴다.** 내보내기가 캔버스만 읽기 때문이다(HUD·인스펙터를 빼려고 일부러 그렇게 짰다). 미시 지도는 아홉 장에 안 들어가고 「들어가면 보이는」 대화형이라 지금은 그게 맞다. 필요해지면 `shoot-pack.py`의 `caption()`처럼 PIL로 같은 JSON에서 합성하면 된다.
- **모바일·좁은 화면.** 2026-09-17에 620px 이하 읽기 모드가 생겼다(R50, `src/app/MobileSheet.tsx`): 지도에는 번호 핀만 남고 카드는 시트 「콜아웃」 탭으로 간다. 핀을 누르면 그 항목으로 스크롤. 620~1023px 사이는 아직 좌우 칸이 지도를 먹는다.
