# DESIGN — 어떻게 보이나

> 볼트 `Works/비주얼파이프라인/`에서 이관 (2026-09-16). 원본 작성 2026-09-07 · 최종 2026-09-08

[SPEC](SPEC.md)의 F-목록을 화면으로 옮긴다. 판정 가능한 규칙만 규칙이다. **v2(2026-09-07 저녁)**: 첫 판의 "편집자의 아틀라스"(종이·명조·해칭 바다)는 River가 기각했다 — 클로드가 늘 내놓는 크림+세리프 룩이고, 자료실과 따로 논다. 이 판의 방향은 둘로 갈린다.

**웹 UI는 자료실과 한 시스템이다.** 자료실이 쓰는 astryx 디자인 시스템(neutral 테마, Pretendard, `light-dark()` 양테마)을 그대로 쓴다. 팀은 두 사이트를 오가며 같은 버튼·같은 패널·같은 배지를 본다. 지도에서만 다른 것은 지도 자체뿐이다.

**v3(2026-09-08)**: River가 기준을 올렸다 — "구독으로 돈을 받을 정도"의 UX/UI·시각화. 실제 판매가 아니라 품질 기준이고, 레퍼런스는 Esri(ArcGIS Map Viewer)·Mapbox(Studio) 급 GIS 제품. v2의 레이아웃·토큰·판정 P1~P12는 그대로 두고, 아래 [제품 등급 기준](#제품-등급-기준-v3)에 베이스맵·인터랙션·패널 밀도·첫인상/성능 네 섹션과 P13~P17을 얹었다.

**지도는 GIS다.** 종이 질감이 아니라 정확한 지리 위에 영역이 "딱딱 맞게" 칠해진 현대 지도첩(Wikipedia 역사지도·Euratlas·Chronas류)의 문법. 영토·속주·도시·강·산·해류·바람·기후 — 전부 데이터이고 객체이며 레이어다. 종이·양피지·토탈워풍은 **내보내기 스킨**으로만 존재한다.

## 원칙 — 통과/반려

| # | 규칙 | 반려 조건 |
|---|---|---|
| P1 | **UI 크롬은 astryx 컴포넌트·토큰만.** 색·간격·반지름·그림자를 직접 정하지 않는다. 자료실 DESIGN의 P1~P8(accent 최대 2·`box-shadow` 테두리·8/12/16/32 스케일·이모지 금지·범례 상시·원시 키 노출 금지)을 그대로 상속 | 하드코딩 색·간격이 크롬 코드에 있으면 반려. 자료실과 나란히 띄웠을 때 다른 시스템으로 보이면 반려 |
| P2 | **지도 위 유채색은 데이터 색뿐** — 세력 팔레트(`팔레트.json`), 수심·고도·기후 램프, 바람·해류 화살표. UI accent(파랑)는 지도 위에 올라오지 않는다 | 지도 위에 UI 파랑이 있으면 반려. 세력 색이 팔레트 값과 다르면 반려 |
| P3 | **영역은 지리에 맞게 칠한다.** 폴리곤은 해안선·강·산맥 경계에 스냅된 실제 지오메트리(Cliopatria + 트레이싱). 채움 50~60% + 같은 색 1px 경계. 러프 다각형은 신뢰도 low로만 허용 | 해안을 넘거나 바다 위에 걸친 영토, 반투명 22% 같은 "힌트" 채움은 반려 |
| P4 | **베이스맵은 지리 정보 계층이다** — 육지·바다·하천·호수·해안선은 Natural Earth/AWMC, 지형 음영·고도색·수심은 DEM·GEBCO에서. 기본 스킨은 밝은 중립색(육지 `#EEF0EC`, 바다 `#D6E4EF`)에 hillshade | 파란 배경 단색, 종이 텍스처, 해칭 바다가 기본 스킨에 있으면 반려 |
| P5 | **모든 지도 요소는 객체다.** 도시·지역·속주·강·산·전투·이동경로·해류·기후 셀까지 클릭하면 패널이 뜬다. 클릭 안 되는 그림은 없다 | 클릭해도 패널이 안 뜨는 지도 요소가 있으면 반려(장식 격자 제외) |
| P6 | **레이어는 카탈로그다.** 왼쪽 레일의 레이어는 manifest에서 생성되고, 켜고 끄고 순서·투명도를 바꾼다. 데이터 없는 레이어는 흐리게 + "P1" 라벨 | 하드코딩된 레이어 버튼이 있으면 반려 |
| P7 | 뜻을 나르는 색·선이 있으면 **범례가 같은 화면에** 있고, 범례는 현재 연도·켜진 레이어를 따라 바뀐다 | 정적 범례, 꺼진 레이어의 항목이 남아 있으면 반려 |
| P8 | 신뢰도 low는 점선 + 60% 불투명, medium 실선 80%, high 100% | 구분 안 되면 반려 |
| P9 | **라벨은 충돌하지 않는다** — MapLibre `text-allow-overlap:false`, 줌별 LOD. 안 보이는 라벨은 안 보이는 게 맞다 | 겹친 라벨이 스크린샷에 있으면 반려 |
| P10 | 모션은 astryx 기본 전환(150~200ms)과 영토 morph 400ms linear 둘뿐. 연도 스크럽은 즉시 | 바운스·스프링·페이드 장식은 반려 |
| P11 | 초상은 룬델 `_초상_1x1/` 것만, 톤 락. "AI 같다"면 폐기 | 톤이 다른 초상, 새 스타일이 섞이면 반려 |
| P12 | **내보내기 스킨과 웹 UI 스킨을 섞지 않는다.** 웹은 astryx 하나. 내보내기는 `export/skins/`에서 고른다(중립 GIS·고지도·신문톤·토탈워풍) | 웹 화면에 내보내기 스킨이 적용돼 있으면 반려 |

## 토큰 — 새로 정하지 않는다

UI 색·서체·간격은 **astryx neutral 테마 토큰**을 그대로 쓴다(자료실 `app/globals.css`와 같은 소스). 자료실이 이미 검증한 값들: 바탕 `rgb(241,244,247)`, 표면 흰색, 텍스트 near-black, accent 파랑 1개, `light-dark()` 양테마, Pretendard(OFL), 본문 17.6px/1.8 `word-break:keep-all`.

지도에만 있는 토큰은 데이터 램프뿐이다.

```css
/* 지도 전용 — UI 토큰이 아니다 */
--map-land:#EEF0EC; --map-sea:#D6E4EF; --map-coast:#8FA3B4; --map-river:#9CBBD3;
--map-label:#111418; --map-label-2:#7C8794;
/* 세력: 관계분석 팔레트.json 미러 (변경 금지) */
--f-rome:#A4243B; --f-carthage:#5B2A86; --f-italic:#C46A1B; --f-greek:#1E6F7A;
--f-gaul:#3E7C4F; --f-numidia:#C79A2E; --f-german:#2E5A34; --f-rebel:#6E4B3A;
--f-egypt:#3E5C8A; --f-neutral:#8A8F98;
/* 램프 — dataviz 스킬의 sequential/diverging 규칙으로 검증 */
--ramp-elev: hypsometric 7단 (저지 녹회 → 고지 갈회 → 설선 흰)
--ramp-depth: 수심 5단 (연안 옅은 청 → 심해 짙은 청)
--ramp-temp: diverging 7단 (한랭 청 ↔ 온난 적, 0 = 회)
--ramp-wind: 풍속 4단 회색 + 방향은 화살표
```

다크 모드는 astryx가 준다. 지도 베이스맵은 다크에서 `--map-land:#2A2E33`·`--map-sea:#1B2129`로만 바꾸고 데이터 색은 그대로(세력색은 양테마에서 대비 검증 완료 — 룬델 실측).

## 객체 패널 (astryx Aside)

초상(룬델 1:1, 세력 링) → 이름(Pretendard 700 22px) + 라틴명 → 연도 줄 → 배지(세력·타입·출처) → **이 해의 상태**(history fold) → 설명(포인트별) → 관계 목록(연도순, 의미군 선 아이콘) → 등장 포인트 → 하단 고정 버튼 3(자료실에서 읽기 · 카드 · 링크). 자료실 객체 페이지와 **같은 순서·같은 배지**여야 한다 — 두 화면이 한 물건임을 말하는 유일한 방법.

장소·지형지물 객체는 초상 대신 국지 지형 썸네일(hillshade 크롭), 기후 셀은 그 해 온도 anomaly 값과 출처.

카드 템플릿(1080×1350)·MP4·PNG 규격은 v1과 같다. 스킨은 색·서체·베이스맵 타일만 바꾸고 레이아웃은 공유한다.

**스킨 시스템(P1, River 2026-09-08)**: Azgaar FMG처럼 **같은 데이터 위에 스타일 프리셋을 갈아끼우는** 구조. 구현은 `buildStyle(manifest, root, ds, { skin })` — 지금 light/dark 두 벌이 그 첫 두 스킨이다. 스킨 = 지도 토큰(MAP.*) + 레이어 페인트 오버라이드 + 라벨 서체 + (있으면) 래스터 톤. 웹 UI 크롬은 안 바뀐다(P12). 후보: neutral · night · oldmap(양피지·해칭 바다·명조) · press(신문톤) · campaign(토탈워풍) · watercolor.

## 상태·빈 화면·접근성

자료실 규칙 승계. 선택 없음이면 패널 없음. 연도 미상 개수는 항상 표시. 로딩은 astryx 진행선. 키보드 `←→`·`Shift`·`Space`·`/`·`Esc`. 색만으로 뜻을 나르지 않는다(선 종류·라벨 병행).

## 제품 등급 기준 (v3)

Esri·Mapbox가 "돈 받는 느낌"을 내는 곳은 셋이다 — 베이스맵 자체의 정밀함, 인터랙션의 부드러움, 패널의 정보 밀도. 여기에 첫인상·성능을 더해 넷. 각 섹션 끝의 판정이 반려 기준이다.

### 1. 베이스맵 — 느낌의 70%

- **데이터**: Natural Earth 10m 전체(육지·해안·강·호수·빙하), bbox 서경 15°~동경 65°, 북위 20°~60°. 서지중해 클립(`rome-753-218/_sources/ne_land_med.geojson`)은 폐기. 해안 1px `--map-coast`, 강은 줌별 `interpolate` 0.4→1.6px.
- **지형**: Mapterhorn DEM → `hillshade-method: multidirectional` 기본 ON. hypsometric color-relief는 **15% 불투명**으로만 — Esri Topographic처럼 은은하게, 세력색이 항상 이긴다. 수심: GEBCO → 청 램프 5단.
- **라벨**: MapLibre 글리프 PBF를 Pretendard로 **빌드타임 자체 생성**(런타임 외부 호출 0, CONSTITUTION 6-2). 도시 rank LOD z3 / z5 / z7. 바다·지역명은 대문자 라틴 자간 0.2em(Esri 관습). 충돌 회피는 P9.
- **다크**: 육지·바다 스왑만, 데이터색 유지(v2 그대로).

| # | 규칙 | 반려 조건 |
|---|---|---|
| P13 | **줌 3~9 어느 시점·어느 위치를 캡처해도 "완성된 지도"로 보인다** | 빈 파란 화면, 클립 경계, 라벨 없는 바다가 보이면 반려 |

### 2. 앱 셸 + 인터랙션 — 풀블리드 지도 위에 떠 있는 카드 (2026-09-08 수정)

River가 가져온 레퍼런스(서울 3D Atlas, `research/20260908_시각레퍼런스_보드.md`)를 보고 셸 문법을 바꿨다. 상단바·고정 레일 그리드(AppShell)가 아니라 **지도가 화면 전체를 채우고, astryx 카드가 그 위에 떠 있다.** Felt·Mapbox Studio도 같은 문법이다. 그리드가 없어서 코드도 적다.

- **기본 뷰**: `pitch 50` · Mapterhorn terrain `exaggeration 2.5` · 살짝 회전한 카메라. "지도"가 아니라 **탁자 위 미니어처 모형**으로 읽혀야 한다. 평면(2D) 토글은 하단 툴바에. 판 가장자리·미니어처 프레이밍(Three.js)은 P1.
- **떠 있는 카드 5 (전부 astryx Surface, `light-dark()` 양테마)**:
  - 좌상 **타이틀 블록**: 상위 맥락 한 줄(`로마제국쇠망사 · 온톨로지 지도`) → 큰 이름(`BC 49` 44px, 데이터셋 이름) → 한 줄 설명. 카드 없이 텍스트만 지도 위에.
  - 좌 **탐색 카드** 300px: 세그먼트 탭(객체 · 레이어 · 장면). 객체 탭은 번호 목록(01, 02 … + ↗), 레이어 탭은 카탈로그(토글·불투명도·범례 인라인), 장면 탭은 SPEC 장면 프리셋 목록.
  - 우 **인스펙터 카드** 360px: §3. 선택 없으면 없다.
  - 하단 중앙 **알약 툴바**: 전체 보기 · 재생(자동 비행) · 2D/3D · 지명 · 전체 화면 — 아이콘 + 라벨(한글 / 라틴 소문자 병기).
  - 우상 **환경 세그먼트**: 낮 · 노을 · 밤 + 계절/기후 레이어가 붙으면 여기(원클릭 분위기). 그 아래 줌 ±·나침반.
  - 하단 **타임라인** 88px: 카드가 아니라 화면 폭 전체의 반투명 띠. 연도 스크럽·틱·시대 띠.
- **각주 줄**: 좌하 "실제 지리 기반 · 지형 2.5× · 출처 n" 한 줄 고정 — 정직한 각주(레퍼런스에서 그대로).
- **Hover**: 모든 객체에 `feature-state: hover` — 채움 +10% 밝기, 외곽 1.5px, 커서 포인터, 툴팁 120ms 지연(이름 · 연도 한 줄, 알약형 라벨). GPU만, DOM 재계산 0.
- **선택**: `feature-state: selected` 외곽 2px 세력색 + 나머지 40% 디밍. 관계 그래프는 인스펙터 아래 패널(1/2홉). 지도 위 선은 좌표 있는 선택의 이웃 ≤12일 때만 — 인물·집단·로마처럼 많으면 관련 지점 강조(`linked`)만.
- **카메라**: 선택 시 `easeTo` 600ms(인스펙터가 가리지 않게 padding 오프셋). 연도 스크럽은 카메라 고정. 자동 비행은 장면 프리셋 순서대로 `flyTo` 체인.
- **키보드**: `←→` 연도 · `Shift+←→` 10년 · `Space` 재생 · `/` 검색 · `Esc` 해제 · `1~9` 레이어 토글 · `V` 2D/3D(`3`은 레이어 3과 충돌 — 2026-09-08 버그 패스에서 발견).
- **좁은 화면**(<1024): 탐색·인스펙터 카드가 하단 시트로, 툴바 유지.

### 3. 패널·타이포 밀도 — ArcGIS 팝업이 아니라 Linear급 인스펙터

- **스케일**: 자료실 본문(17.6/1.8)은 읽기용. 패널은 자료실 DESIGN의 compact 프리셋 — 이름 20/600, 메타 13/500 `--muted`, 본문 14/1.55, 라벨 11/600 대문자 자간 0.06em. 행 32px, 섹션 간격 16, 좌우 패딩 16. 전부 astryx 토큰 값.
- **구성**: v2 순서 유지(초상→이름→연도→배지→이 해의 상태→설명→관계→포인트→버튼 3). **관계 목록은 의미군별 접이식 그룹**(동맹 4 · 적대 7 · 통치 2…) + 숫자 배지. 행 hover 시 지도에서 상대 객체가 펄스 1회(200ms, P10 범위).
- **숫자**: tabular-nums. 연도는 "BC 44" 접두 고정.
- **빈 값**: 값 없는 필드는 행 자체가 사라진다("—" 금지). 연도 미상은 "연도 미상 · 출처 포인트 12"처럼 근거를 같이.
- **출처 배지 3종**(포인트·기번·외부)은 자료실 컴포넌트 import.

### 4. 첫인상·빈 상태·성능 — 구독 버튼 앞에서 판가름나는 것

- **첫 화면**: 로딩 중에도 빈 파랑 금지 — 베이스맵이 데이터보다 먼저 뜨고, 데이터 레이어는 200ms 페이드로 얹힘. 첫 진입은 **장면 프리셋**(SPEC 첫 장면 BC60 카이사르)이 카메라·연도·선택까지 세팅된 상태. "뭘 해야 하지"가 0초.
- **빈 상태**: 검색 결과 없음 · 레이어 데이터 없음(P1 레이어) · 연도 밖 객체 — 각각 한 줄 설명 + 다음 행동 버튼 1개. 일러스트 금지.
- **성능 예산**: 첫 페인트 1.5s(4G) · JS 400KB gz(Three.js 토큰은 동적 import) · 초기 데이터 1MB 이하(graph.json은 패널 열 때 지연 로드) · 60fps 스크럽·팬 · Lighthouse 성능 90+.
- **반응형**: 1280 기본 · 1024~1279 Aside 오버레이 · <1024 태블릿(레일→하단 시트, 타임라인 유지) · 모바일은 **읽기 전용**(스크럽·탭만, 그래프 오버레이 꺼짐).
- **접근성**: 포커스 링 astryx 기본 · 지도 객체 키보드 순회는 관계 목록으로 대체 · 대비 4.5:1 · `prefers-reduced-motion`이면 morph·easeTo 즉시.
